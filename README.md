# MathGame — обучающая математическая 2D-игра (курсовая работа)

Обучающая игра для детей 6–16 лет: сюжетные уровни, в которых нужно решать
математические примеры, чтобы победить "големов" (тип уровня **Башни**) или
выбрать правильную дверь (тип уровня **Двери**). Подробности геймдизайна —
в задании курсовой; техническая архитектура описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Версия Unity

**Unity 6.3 LTS** (внутренний номер сборки начинается с `6000.3.`), последний
доступный патч в Unity Hub. Почему именно эта версия — см. раздел "Установка
Unity" в переписке/ниже: это актуальная LTS-ветка с поддержкой до конца 2027
года (предыдущая ветка 6.0 LTS теряет поддержку уже в октябре 2026 — раньше,
чем закончится курсовая).

## Как открыть проект

1. Установить Unity Hub и Unity 6.3 LTS (модуль **Windows Build Support** +
   при установке редактора отметить шаблон **2D**).
2. В Unity Hub → `Open` → `Add project from disk` → выбрать эту папку
   (`Game`, ту, где лежит этот README).
3. Дождаться первого импорта ассетов (может занять несколько минут — Unity
   создаёт `Library/`, `.meta`-файлы и т.д., это нормально и в первый раз
   всегда долго).

## Структура проекта

```
Assets/_Project/
  Scripts/            — весь код, разложен по слоям (см. ARCHITECTURE.md)
  ScriptableObjects/   — данные уровней и мини-игр (ассеты, не код)
  Prefabs/             — префабы сцены (герой, голем, дверь, UI-экраны)
  Scenes/              — Boot / Menu / Gameplay
  Art/, Audio/          — арт и звук (пока плейсхолдеры)
  Editor/              — редакторские утилиты (например, генератор тестовых уровней)
docs/                  — документация проекта
```

Всё, что генерируется самим Unity (`Library/`, `Temp/`, `obj/`, `.vs/` и
т.п.), находится в `.gitignore` и никогда не попадает в репозиторий — эти
папки пересоздаются автоматически при открытии проекта.

## Настройки игры

Все настройки (диапазон чисел, разрешённые операции, рост сложности, лимит
времени, упрощённый режим для дверей, сброс прогресса) — в экране
"Настройки" в главном меню. Они не привязаны к профилю, хранятся в одном
файле локально на устройстве.
